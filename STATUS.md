**Standing cloud rules (P0.10, F95):**
- **A powered-off server still bills.** Hetzner bills until the server is *deleted*, regardless of power state. The off switch is `hcloud server delete`, never `hcloud server poweroff`.
- Billing is hourly **rounded up** (a 20-minute box costs a full hour), capped at the monthly price. No daily minimum, so short bursts are cheap and safe.
- **Every session's orient step runs `hcloud server list`** — a forgotten box is the only real way to burn this cap (ccx33 = $6.27/day; a ccx63 would have been $38.70/day).
- Delete at the end of every run; job scripts should end in `hcloud server delete`. Never leave an idle instance (PROCESS.md).
