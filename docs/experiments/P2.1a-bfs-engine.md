# P2.1a — search engine v1 (frame-layered BFS on the QuickNES core) and the 1-1 third-room probe

**Goal.** A first in-process search engine on the stage-1 core and a first run on the 1-1 objective
(H21): from the third-room load, find a flagpole grab at QuickNES frame ≤ 1284 (the WR grabs after
frame 1285; T = 370 for grabs ≥ 1261, so T_set ≤ 1813 ⇒ the next framerule, −21 frames).

**Setup.** `src/search/bfs.c` (→ `build/bfs`): dlopen the core, run the WR inputs to a root frame,
then per layer expand every distinct state with the 16 A/B/Left/Right combinations, dedup by FNV-1a
of RAM $0000–$00FF + $0300–$07FF (stack/OAM excluded), terminal when GES ($0E) becomes 4/5 (then run
input-free to StarFlagTaskControl = 4 → T_set), dead on GES 6/11 or Y_HighPos > 1, optional
deadline pruning. Root = after QuickNES frame 923 (= FCEUX row 927, the third-room load; control
starts after frame 1045). Machine: Linux box, single thread, 6 GB state cap (≈245k states/layer at
12,792 B per savestate).

**Commands.**
```
gcc -O2 -o build/bfs src/search/bfs.c -I third_party/QuickNES_Core/libretro/libretro-common/include -ldl
./build/bfs third_party/QuickNES_Core/quicknes_libretro.so 'roms/Super Mario Bros. (W) [!].nes' \
   data/wr/wr_inputs.bin --input-skip 2 --root 923 --replay-check          # evaluator check
./build/bfs ... --root 923 --mem-mb 6000 --deadline 1284 --target-x 3158 --out runs/bfs11_test
./build/bfs ... --deadline 1284 --target-x 3158 --bound greedy             # aggressive bound
```

**Results.**
1. Evaluator: replaying the WR from the root reproduces grab after frame 1285 (GES 5, Y 164,
   X 89, T 370) and T_set after frame 1814 (ITC 20) — matches F32/F29 (FCEUX rows 1289/1818).
2. Growth, full-state dedup, no pruning: layers before control stay at 16 states (joypad bytes
   only); from control: 16 → 127 → 936 → 5,402 → 26,247 → 107,757 → ≥245,300 (cap hit at frame
   1052, 6 frames into control; 204 s for the last layer). ≈ ×5 per layer; dup ratio only ~3.5.
3. Deadline pruning with the sound bound (speed +≤2 units/frame, cap 40, x += 16·speed/256 px):
   nothing pruned in those layers — the bound's frontier reaches x = 3158 px at frame 1272,
   12 frames before the deadline, so every state within ~30 px survives. The WR sits 18.7 px
   (7.5 frames) behind this bound from frame 1079 on (all of it lost in the acceleration phase
   where the bound over-allows).
4. Aggressive bound (exact ground-running dynamics, adder $E4 per frame): prunes **everything** at
   the first control frame — i.e. pure ground running cannot reach the pole by 1284 at all. The WR
   beats ground running with the airborne/turnaround acceleration (below), so this bound is
   unsound and was only useful as a probe.
5. WR acceleration profile (dump rows 1046–1079, QuickNES rows): at control Mario presses L+R
   (facing := 3 ≠ moving dir 1) and jumps; airborne with the **doubled** adder (2×$98) speed rises
   ≈1.1–1.3/frame to the airborne cap 24 (speed < 25 in the air ⇒ MaxRight $18), lands at
   1068, then taps Left (facing 2 ≠ moving 1) and accelerates 26 → 40 at ≈1.8/frame (2×$E4)
   by 1079: 0 → 40 in 33 frames. Then speed 40 to x = 3157.3 at frame 1280, **stops (speed 0)**
   and creeps to the grab at 3161 over 5 frames — the flagpole-glitch setup.
6. Third-room entry state is fixed: the pipe exit sets X = 2616 (page 10, $38), `InitializeArea`
   clears $0705/$57 (subpixel/speed 0), control at load+122 — the room is the same puzzle in
   every 1-1 run; only the frame number and timer phase differ.

**Conclusion.** The engine works and the evaluator is exact, but full-state BFS with 12.8 KB
savestates cannot cover even the acceleration phase (≥1e6 states within the sound bound; the
relevant band is ~19 px wide × subpixel × speed × air states). Options, in order of leverage:
(a) a physics-level core with ~32-byte states (P1.2 or a validated player-physics model) — needed
for any room-scale exact search; (b) a **flat-world frontier** (area/enemy parsers pointed at
their terminators, block buffer flattened) computed with physics-class + max-P dominance, which is
a sound relaxation for "earliest arrival at x ≥ 3158" and would prove or refute the third room
in isolation; (c) tighter sound acceleration bounds from the state machine (facing/moving dir,
air cap 24, adders $98/$D0/$E4 ×2) — derivable but fiddly. The unit is split: P2.1a (this) done;
P2.1b = (b)+(c) on the current core; P2.1c = full room search once P1.2 exists.
